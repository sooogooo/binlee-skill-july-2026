# 项目介绍

## 长版

医美行业最缺的不是更多术语，而是更可靠的判断。

Binlee Skills 是一套面向医美行业的 Agent Skills：它把 582 篇本地文章语料、行业经营分析、机构运营、医生 IP、合规风险、消费者决策和公共传播组织成可复用的 AI 工作流。

它服务四类人：

- 给机构老板：把“流量、增长、机会”还原成定位、交付、组织和风险的经营问题。
- 给医生：把临床能力变成可解释、可验证、不过度承诺的专业表达。
- 给监管与研究者：把行业事件、传播话术与治理边界放在同一张图里观察。
- 给普通消费者：在被种草之前，先学会澄清需求、准备面诊、识别利益冲突和理解不确定性。

Binlee 的核心不是替人做医疗决定，而是让 AI 在面对医美问题时知道：哪些是作者观点，哪些是跨文归纳，哪些必须查最新法规、临床证据或产品状态；哪些话可以帮助理解，哪些话会把信息差变成消费压力。

它支持 Codex、Claude Code、Gemini CLI 和 OpenCode。仓库保留一份 canonical `SKILL.md`，安装器负责把同一套技能映射到各 CLI 的标准发现目录，不再为不同工具维护互相漂移的复制品。

如果你希望 AI 不只会写“医美趋势”，而是能在证据、边界、行动和信任之间做判断，Binlee 是为这个问题准备的。

## 一句话

**Binlee Skills：让 AI 进入医美行业时，先学会判断，再学会表达。**
