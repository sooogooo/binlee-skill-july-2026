# CLI / marketplace listing copy

## Product name

Binlee Skills · 医美信任闭环

## Short description

面向医美经营、医生 IP、合规、消费者决策、公共传播和入口导航的跨 CLI Agent Skills。

## Long description

Binlee Skills 将医美行业文章语料与六类工作流、一个帮助路由入口组合成一套可安装的 Agent Skills：战略、机构运营、医生 IP、合规风险、消费者决策、公共传播，另附本地语料检索与更新能力。

它支持 Codex、Claude Code、Gemini CLI 和 OpenCode，使用同一份 canonical `SKILL.md`，通过安装器映射到各 CLI 的发现目录。输出要求区分文章观点、跨文归纳和需实时核验的当前事实；消费者相关任务不提供诊断或个体化项目推荐。

## Feature bullets

- 577 篇按原文来源去重的本地医美文章：正文、摘要、FAQ、日期和原文链接可检索。
- 六个专业决策入口：经营、运营、医生、合规、消费者、传播。
- 一个帮助路由入口：不知道从哪里开始时，给出推荐 skill 和可复制提示词。
- 跨 CLI 安装：一套 skill，四个原生 Agent Skills 目录。
- 时效纪律：政策、价格、产品状态和临床证据必须另行核验。
- 消费者边界：帮助理解与准备，不制造焦虑，不替个人做医疗决定。
