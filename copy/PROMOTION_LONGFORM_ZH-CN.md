# 别让 AI 只会写“医美趋势”：Binlee Skills 把判断、边界和消费者保护装进了工作流

**摘要：** 一套面向机构、医生、研究者和普通消费者的医美 Agent Skills，帮助 AI 先分清证据，再给出行动。

医美行业不缺观点。

缺的是一种更可靠的判断方式。

你可能见过这样的 AI 输出：开头是“行业正在迎来新机遇”，中间是几段趋势判断，结尾落到“抓住窗口、提升转化、打造差异化”。看起来很完整，读完却不知道下一步该做什么。

更麻烦的是，医美问题从来不只是内容问题。它同时牵涉医疗边界、消费者选择、机构经营、医生职业声誉和公共传播。一个听起来很顺的句子，可能在现实里变成一条夸大宣传；一句“建议尽快行动”，可能只是销售话术换了件外套。

所以我们做了 Binlee Skills。

## 它不是“会写医美文案”的提示词包

Binlee Skills 是一组可以安装到 Codex、Claude Code、Gemini CLI 和 OpenCode 的 Agent Skills。仓库里有一份统一的 `skills/` 真源，包含八个入口：一个帮助路由、六个专业工作流和一个本地语料库入口：

- `binlee-med-aesthetics-strategy`：看行业周期、定位、竞争、定价和经营选择。
- `binlee-clinic-operations`：看组织、渠道、交付、医生协作和运营韧性。
- `binlee-doctor-ip`：帮医生建立专业定位、内容支柱和更可信的个人品牌。
- `binlee-compliance-risk`：检查宣传、医疗边界、记录、消费者保护和信任风险。
- `binlee-consumer-decision`：帮助普通消费者澄清目标、准备面诊、识别利益冲突。
- `binlee-public-communication`：把专业内容讲得准确、清楚、不靠制造焦虑传播。
- `binlee-source-library`：检索、引用和刷新本地文章语料。
- `binlee-help`：在不知道从哪里开始时，快速选择入口并生成可复制提示词。

这八个入口不是八套互相打架的观点。七个专业入口共享从 `drli.beaucare.org` 整理并按原文来源去重的 577 篇文章全文、摘要、FAQ、日期和原文链接；帮助入口负责路由，也共享一条很朴素的证据纪律：

**文章里的判断，不自动等于今天仍然有效的事实。**

## 给机构老板：别把增长当成唯一问题

机构经营者最容易遇到的，不是“没有想法”，而是所有问题都被叫作增长问题。

咨询量下降叫增长问题，医生排班失控叫增长问题，交付投诉增加也叫增长问题。最后大家一起追渠道、做促销、改话术，真正的瓶颈反而越来越难看见。

Binlee 会先把问题拆开：需求、转化、临床交付、组织协作、经济模型和治理边界分别出了什么状况？一个新项目值得做，是因为真的有临床能力和稳定需求，还是因为短期流量信号看起来很诱人？一个“高转化”方案，是否把不透明价格、过度承诺或信息不对称当成了商业模式？

最后得到的不是一篇泛泛的行业分析，而是一份可以拿进会议室的决策备忘录：关键假设、选项、验证实验、负责人、指标、复盘时间，以及不能拿来交换的消费者风险。

## 给医生：个人 IP 不是销售脚本的高级版本

医生做内容，最容易掉进两个坑。

一个是把专业内容写成术语展览；另一个是把医生身份变成效果承诺的背书。

Binlee-doctor-ip 更关心三个问题：你真正擅长什么？患者反复遇到的决策困难是什么？哪些内容是在解释专业，哪些内容已经越过了个体化医疗建议的边界？

它会帮助医生把能力整理成可长期输出的内容支柱，把复杂判断翻译成普通人听得懂的语言，同时审查案例隐私、利益冲突、恐惧营销和未经核验的功效表述。

真正有生命力的医生 IP，不是“看起来很厉害”，而是让读者知道：这位医生如何思考，哪些地方会承认不确定，什么时候会建议你先别做决定。

## 给监管与研究者：从话术里看见制度问题

很多行业研究停在事件列表：谁说了什么，哪种项目变热，哪个平台出现了什么内容。

Binlee 提供另一种切入方式。把一条公开表达拆成事实、解释、价值判断和不确定性；再把传播者的利益、受众的误解成本、证据留存和可能的消费者伤害放到同一张图里。

这样看，合规就不只是“这句话能不能发”的文字检查，也包括机构边界、临床决策、病历记录、内容分发和消费者保护之间的连接。

研究者可以用本地文章库追溯一条行业观点从哪里来、在不同文章里如何变化，再把历史语料与当下的法规、政策、市场数据分开核验。它不会把旧文章伪装成最新结论，这一点听起来保守，实际上是研究可信度的底座。

## 给普通消费者：先把决定权拿回来

这是我们特别想强化的一条入口。

普通消费者往往不是缺信息，而是被太多“看似专业”的信息推着走：你应该立刻改善、这个项目正适合你、今天有名额、错过就要等下一轮。等到坐进咨询室，很多人已经忘了自己最初想解决的到底是什么。

`binlee-consumer-decision` 不会根据几句描述替你诊断，也不会推荐某个项目、医生或机构。它做的是把下一步变得更清楚：

- 你想改善的是具体问题，还是被内容制造出来的焦虑？
- 对方说的是医生判断、机构销售、用户体验，还是广告承诺？
- 你需要问清楚哪些替代方案、风险、恢复期、费用和后续安排？
- 哪些话术值得暂停，而不是立刻付款？
- 什么时候应该停止线上讨论，去找合格的线下专业帮助？

这不是把消费者变成“更会砍价的人”。它是把消费者从被说服的位置，带回到可以提问、比较、核验和暂缓的位置。

**医美内容真正的传播价值，不是让人更快下单，而是让人更有能力做决定。**

## 给内容生产者：把“专业”写成可验证的表达

一篇内容要有传播力，当然需要标题、结构和节奏。但在医美场景里，传播力越强，越不能省略边界。

Binlee-public-communication 会先问：这篇内容会影响读者做什么决定？谁在说？有什么利益关系？读者最可能误解哪一句？如果误解发生，代价是什么？

然后再把文章拆成 claim map：哪些是可以核验的事实，哪些是作者解释，哪些是价值判断，哪些仍然不确定。最后检查术语是否过密、有没有隐性推广、有没有把个案写成普遍结果、有没有用恐惧和羞耻推动行动。

这套方法也适合博客、公众号、视频脚本、机构 FAQ 和监管沟通材料。它不要求每篇文章都冷冰冰，而是要求情绪和证据各自站在应该站的位置上。

## 现在就可以安装

整套技能支持一条命令安装：

```bash
npx skills add sooogooo/binlee-skill-july-2026
```

先看有哪些入口：

```bash
npx skills add sooogooo/binlee-skill-july-2026 --list
```

只安装消费者决策入口：

```bash
npx skills add sooogooo/binlee-skill-july-2026 \
  --skill binlee-consumer-decision
```

安装后，你可以这样开始：

```text
请使用 binlee-consumer-decision，帮我整理第一次医美面诊前要确认的问题。
```

或者：

```text
请使用 binlee-med-aesthetics-strategy，判断我们应该扩张项目，还是先修复交付系统。
```

再或者：

```text
请使用 binlee-public-communication，把这篇医生科普改成普通消费者看得懂、又不构成广告承诺的版本。
```

## 我们希望它留下什么

不是更多“医美趋势”文章。

不是一套把每个人都推向消费的自动化话术。

我们更希望它留下四种能力：机构能看见经营选择背后的代价，医生能把专业变成可信的公共表达，研究者能把行业叙事和治理边界放在一起观察，消费者能在做决定之前多问几个真正重要的问题。

AI 可以帮我们更快处理信息，但速度不应该替代判断。尤其在医美这样同时涉及身体、身份、金钱和信任的领域，先把边界说清楚，才谈得上效率。

Binlee Skills 想做的，就是给 AI 加上一层这样的工作习惯：先找证据，分清观点，承认不确定，给出下一步；必要时，明确告诉你它不能替你决定。

如果你也希望 AI 进入医美行业时，先学会判断，再学会表达，可以从这条命令开始。

```bash
npx skills add sooogooo/binlee-skill-july-2026
```
